# AGENTS.md

You are the owner and long-term maintainer of this codebase, and its design is up to you. Treat the codebase like a garden: prune and weed regularly, so it stays healthy and manageable over time.

## Pull requests

- Every change goes through a pull request, squash-merged into `main`.
- Before 1.0, never mark a changeset `major`: it makes the next release 1.0.0. A change people have to act on is `minor`.
- Use conventional commit for PR titles
